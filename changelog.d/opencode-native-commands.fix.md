- **opencode gets native slash commands.** `install.sh --harness opencode` now symlinks `commands/*.md` into `~/.config/opencode/commands/` instead of delivering them as skills. Re-run the installer to pick it up. Command-skills in `~/.agents/skills` from other harnesses or an earlier opencode install remain (accepted duplication); on an opencode-only install, delete the `~/.agents/skills/<name>` dirs containing `.from-command`.
