- **opencode v2 is a fifth harness.** `install.sh --harness opencode` links the `ai-memory` plugin into `~/.config/opencode/plugins/` and the `ai-memory-explore` agent into `agents/`. The plugin injects the full `<memory:*>` payload on every model call and runs the infra guard (deny-list, protected paths, read-only role policy) on `execute.before`. `executor.sh` can delegate to it with `AI_MEMORY_EXECUTOR_<ROLE>=opencode:<provider>/<model>`; `--run --clean` returns only the final message. Executor runs force `--standalone`, require the global plugin and disable Code Mode. New manifest keys `plugins_dir`/`plugin_file`/`exec_probe_cmd`. Export `OPENCODE_DISABLE_CLAUDE_CODE_SKILLS=1` to avoid double skill listings; restart the opencode service after install. See `docs/harnesses/opencode.md`.
