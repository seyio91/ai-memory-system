- **`install.sh` and `sync-system.sh` now require `python3` 3.11 or later.** Both check up front and abort, changing nothing, when `python3` is missing or older. macOS ships 3.9 with the Command Line Tools, so install a newer one with Homebrew (`brew install python`) or pyenv. `sync-system.sh --dry-run` skips the check. The first upgrade onto this release is performed by the previous `sync-system.sh`, which has no check: on a too-old `python3` the tree moves to the new version and `install.sh` then stops. Install `python3` 3.11 or later and re-run `/sync-system`.
- **In guarded contexts (executor roles, or Claude with `AI_MEMORY_GUARD_SCOPE=all`), the guard now denies when no `jq`/`python3` is found.** Previously Claude's main session failed open with a warning; executor roles already denied. A missing or empty deny-list still fails open in the main session.
