- **Index regeneration and local task writes no longer corrupt on spaces or concurrent runs.** `regenerate-index.sh` handles a memory root containing spaces, aborts with `index.md` untouched when enumeration fails, and stages through unique temp files with a single atomic replace (`/.index.*` is gitignored). The local task provider publishes a captured task with an exclusive hard link (a taken ref gets the next `-N`, never overwritten), writes updates atomically, keeps file modes across status moves, and an interrupted status move stays listed under its new status and completes on retry. The data root must support hard links.
