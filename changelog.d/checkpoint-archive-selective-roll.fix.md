- **`/checkpoint-archive` keeps in-flight checkpoints.** It used to classify entries but still archive the whole `## Checkpoints` section, so unfinished work left `working.md` and had to be restored by hand. It now rolls only superseded and closed entries and leaves in-flight ones in place, in order. `checkpoint-archive.sh` gained `--list` (numbered entries) and a repeatable `--keep <n>`. An invalid keep exits 2 and writes nothing.
- **`checkpoint-archive.sh` refuses malformed input in every mode.** A duplicate target `## ` heading, or a code fence left open that swallows the target section, now exits 2 and writes nothing. That applies to `/promote-memory`'s learnings roll too, where it could previously roll the wrong span. A slug that is not a plain name (for example `--keep=2` placed after the working file) is a usage error instead of a filename. Tilde and long backtick fences are now recognised the same way the session payload renders them.
