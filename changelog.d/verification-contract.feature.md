- **Plans carry a checkable verification contract.** `/new-plan` and `/start` scaffold R-id criteria, per-phase `Files touched` / `Risk` / `Depends` / `Verify`, `## Non-goals` and a Goal `**Before:**` / `**After:**` from one shared partial (`apply-partial.sh` now re-syncs blocks in place). Lint rule 20 warns (`plan-contract:`) on post-cutover plans that break it. `check-plan-drift.sh` names files changed outside a plan's `Files touched` (exit 0 clean, 1 drift, 3 pre-cutover, 2 otherwise). The `plan-feasibility` brief returns READY, CAUTION or REVISE before the first delegation. `/plan-archive` moves a plan's `plans/<slug>.baseline/` dir with it.
- **The validator checks more than the criteria.** Every pass covers the criteria plus the phase `Verify:`, and a PASS needs a command with output or a `file:line`. A `goal_check: yes` brief (last phase, `scope: final`) adds the Goal check (`VERDICT: BLOCKED (goal)`) and the drift check. Task executors end with `diverged: no | yes — <what>`; `executor.sh --role task --run` prepends the rule. The doctrine gains an evidence-before-claims rule.
